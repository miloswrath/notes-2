# Templates

Starter templates for the vault domains.

## Δ Read
- [[Δ Read Template]] — for crystallized knowledge, references, and source-backed notes.

## Θ Write
- [[Θ Idea Template]] — for raw ideas, working thoughts, and exploratory material.

## Ψ Execute
- [[Ψ Project Template]] — for active projects and deployment of knowledge + ideas.

## Metadata choices
Based on initial setup preferences:
- Common rich metadata: `created`, `updated`, `status`, `tags`, `aliases`, `related`, `sources`/`links`, `confidence`.
- Δ read linking metadata: `type`, `topics`, `source_type`, `source`, `author`, `ideas`, `projects`.
- Θ idea workflow metadata: `type`, `priority`, `energy`, `next_action`.
- Ψ project minimal metadata: `status`, `tags`, `due` plus the common rich fields.
